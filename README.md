# Character and Word Counter

---

## 📌 Description

The Character and Word Counter is a simple web application that counts characters, words, and sentences as the user types.

The counters are updated instantly using JavaScript and DOM manipulation.

---

## 🎯 Objective

The main objective of this task is to practice:

- Input events
- JavaScript string methods
- DOM manipulation
- Live content updates
- Text processing
- Regular expressions

---

## 🛠️ Technologies Used

- HTML5
- CSS3
- JavaScript
- DOM Manipulation
- Regular Expressions
- CSS Flexbox
- Responsive Design

---

## ✨ Features

- Live character count
- Live word count
- Live sentence count
- Updates automatically while typing
- Textarea for entering text
- Handles empty text correctly
- Responsive design
- Works on desktop, tablet, and mobile devices
